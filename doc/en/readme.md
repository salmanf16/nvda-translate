# NVDA Translate

Hey there! This is a simple, super-fast translation addon for NVDA. It's designed to translate any spoken text, game dialogues, or chat messages in real-time, instantly. Whether you are gaming, chatting, or browsing, this addon has got your back.

---

## What makes it great?

- **Real-Time Translation**: Translates text instantly as soon as NVDA speaks it.
- **Choose Your Target Language**: You can set the translation language to be completely different from your NVDA interface language! For example, if your NVDA is set to Arabic, you can still translate spoken text into English or any of the 80+ supported languages.
- **Super Fast & Lightweight**: No lag, no system bloat. It's built to run in the background without you even noticing.
- **Smart Caching**: It remembers previous translations. If a phrase is spoken again, it loads instantly from memory without waiting for the internet.
- **Multiple Translation Engines**: Easily switch between Google Translate, Lingva, or LibreTranslate right from the settings.

---

## How to Install

1. Download the `translate.nvda-addon` file.
2. Double-click or press Enter on the file.
3. Click **Yes** when NVDA asks if you want to install it.
4. Restart NVDA, and you are good to go!

---

## Hotkeys (Gestures)

Here are the default shortcuts to control the addon (you can customize them in NVDA Preferences -> Command Gestures):
- **NVDA+Shift+Control+T**: Turn translation on or off.
- **NVDA+Shift+C**: Copy the last translated text to your clipboard.
- **NVDA+Shift+F** (press twice quickly): Clear the translation memory for the active app.
- **NVDA+Shift+Control+F** (press twice quickly): Clear all translation memory on your system.

---

## Settings & Customization

Go to **NVDA Menu -> Preferences -> Settings -> Translate** to configure:
1. **Translation Engine**: Choose Google, Lingva, or LibreTranslate.
2. **Target Language**: Choose your destination language (can be different from NVDA's active language!).
