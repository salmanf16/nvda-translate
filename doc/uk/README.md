# Перекладач NVDA 🌐

Привіт! Це простий та надшвидкий додаток для перекладу в NVDA. Він розроблений для миттєвого перекладу будь-якого розмовного тексту, ігрових діалогів або повідомлень чату в режимі реального часу. Незалежно від того, чи ви граєте, спілкуєтесь у чаті чи переглядаєте веб-сторінки, цей додаток вам допоможе.

### Що робить його чудовим?

- **Переклад у реальному часі**: Миттєво перекладає текст, щойно NVDA його промовляє.
- **Вибір мови перекладу**: Ви можете встановити мову перекладу, яка повністю відрізняється від мови інтерфейсу NVDA! Наприклад, якщо у вашому NVDA встановлено українську мову, ви все одно можете перекладати промовлений текст на англійську або будь-яку з понад 80 підтримуваних мов.
- **Надзвичайно швидкий і компактний**: Без затримок, без навантаження на систему. Додаток розроблений так, щоб працювати у фоновому режимі, і ви навіть не помітите його роботи.
- **Розумне кешування**: Додаток запам’ятовує попередні переклади. Якщо фраза промовляється знову, вона миттєво завантажується з пам’яті, не чекаючи на підключення до Інтернету.
- **Кілька сервісів перекладу**: Легко перемикайтеся між Google Translate, Lingva або LibreTranslate прямо в налаштуваннях.

### Як встановити

1. Завантажте файл `translate.nvda-addon`.
2. Двічі клацніть по файлу або натисніть клавішу Enter.
3. Коли NVDA запитає, чи хочете ви встановити цей файл, натисніть **Так**.
4. Перезапустіть NVDA — і все готово!

### Комбінації клавіші (жести)

Ось стандартні комбінації клавіш для керування додатком (ви можете налаштувати їх у Налаштуваннях NVDA -> Жести вводу):

- **NVDA+Shift+Control+T**: Увімкнути або вимкнути переклад. 
- **NVDA+Shift+C**: Копіювати останній перекладений текст у буфер обміну. 
- **NVDA+Shift+F** (швидко натиснути двічі): Очистити пам’ять перекладів для активної програми. 
- **NVDA+Shift+Control+F** (швидко натиснути двічі): Очистити всю пам’ять перекладів у вашій системі.

### Налаштування та персоналізація

Щоб налаштувати ці параметри, перейдіть до **Меню NVDA -> Параметри -> Налаштування -> Переклад**:

1. **Сервіс перекладу**: виберіть Google, Lingva або LibreTranslate.
2. **Мова для перекладу**: виберіть мову перекладу (вона може відрізнятися від поточної мови NVDA!).
