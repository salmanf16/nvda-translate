## العربية

أهلاً بك! هذي إضافة بسيطة وسريعة لبرنامج NVDA، فكرتها تترجم لك أي كلام ينطق به قارئ الشاشة في نفس اللحظة. سواء كنت تلعب، أو تدردش مع أصدقائك، أو تتصفح موقع بلغة ثانية، الإضافة هذي راح تترجم لك كل شيء فوراً وبدون أي تعقيد.

### وش المميزات الرهيبة فيها؟

* **ترجمة فورية وسريعة**: الإضافة تترجم لك الكلام مباشرة أول ما ينطق به NVDA.
* **اختر اللغة اللي تبيها (حتى لو مختلفة عن لغة الـ NVDA)**: هذي ميزة بطلة! إذا كان برنامج NVDA عندك باللغة العربية مثلاً، بس تبي الترجمة تكون للغة الإنجليزية أو العكس، تقدر بكل بساطة تروح للإعدادات وتحدد لغة الترجمة اللي تبيها بشكل مستقل تماماً عن لغة البرنامج نفسه. الإضافة تدعم لغات كثيرة جداً (أكثر من 80 لغة!).
* **سريعة وخفيفة جداً**: ما تسبب أي بطء أو تعليق للجهاز، وحجمها صغير جداً.
* **تحفظ الترجمات السابقة (ذاكرة ذكية)**: الكلمات اللي تترجمها أكثر من مرة تنحفظ في الذاكرة المؤقتة عشان تظهر لك فوراً بدون ما تنتظر الإنترنت.
* **محركات ترجمة متعددة**: تقدر تختار بين ترجمة جوجل (Google Translate) أو المحركات الثانية مثل Lingva و LibreTranslate من الإعدادات.

### كيف أثبت الإضافة؟

بسيطة جداً:
1. حمل ملف الإضافة `translate.nvda-addon`.
2. اضغط عليه مرتين (أو اضغط Enter).
3. راح يسألك الـ NVDA إذا كنت تبي تثبتها، اختر **نعم** (Yes).
4. أعد تشغيل NVDA وراح تكون جاهزة للعمل!

### كيف أتحكم فيها؟ (الاختصارات)

هذي أهم الاختصارات اللي تحتاجها (وتقدر تغيرها من إعدادات اختصارات NVDA إذا تبي):
* **NVDA+Shift+Control+T**: يشغل أو يطفي الترجمة.
* **NVDA+Shift+C**: ينسخ آخر نص تم ترجمته للحافظة عشان تشاركه بسهولة.
* **NVDA+Shift+F** (اضغطها مرتين بسرعة): يمسح ذاكرة الترجمة الخاصة بالتطبيق اللي شغال عليه حالياً.
* **NVDA+Shift+Control+F** (اضغطها مرتين بسرعة): يمسح كل ذاكرة الترجمة المحفوظة في الجهاز.

### الإعدادات وضبط اللغات

عشان تضبط لغة الترجمة والمحرك:
روح لـ **قائمة NVDA -> تفضيلات -> إعدادات -> الترجمة (Translate)**:
1. اختر **محرك الترجمة** اللي يريحك.
2. حدد **اللغة الهدف (Target Language)** اللي تبي الترجمة تتحول لها (وتقدر تخليها مختلفة تماماً عن لغة الـ NVDA زي ما تحب!).

### شكر خاص

## English

Hey there! This is a simple, super-fast translation addon for NVDA. It's designed to translate any spoken text, game dialogues, or chat messages in real-time, instantly. Whether you are gaming, chatting, or browsing, this addon has got your back.

### What makes it great?

- **Real-Time Translation**: Translates text instantly as soon as NVDA speaks it.
- **Choose Your Target Language**: You can set the translation language to be completely different from your NVDA interface language! For example, if your NVDA is set to Arabic, you can still translate spoken text into English or any of the 80+ supported languages.
- **Super Fast & Lightweight**: No lag, no system bloat. It's built to run in the background without you even noticing.
- **Smart Caching**: It remembers previous translations. If a phrase is spoken again, it loads instantly from memory without waiting for the internet.
- **Multiple Translation Engines**: Easily switch between Google Translate, Lingva, or LibreTranslate right from the settings.

### How to Install

1. Download the `translate.nvda-addon` file.
2. Double-click or press Enter on the file.
3. Click **Yes** when NVDA asks if you want to install it.
4. Restart NVDA, and you are good to go!

### Hotkeys (Gestures)

Here are the default shortcuts to control the addon (you can customize them in NVDA Preferences -> Command Gestures):
- **NVDA+Shift+Control+T**: Turn translation on or off.
- **NVDA+Shift+C**: Copy the last translated text to your clipboard.
- **NVDA+Shift+F** (press twice quickly): Clear the translation memory for the active app.
- **NVDA+Shift+Control+F** (press twice quickly): Clear all translation memory on your system.

### Settings & Customization

Go to **NVDA Menu -> Preferences -> Settings -> Translate** to configure:
1. **Translation Engine**: Choose Google, Lingva, or LibreTranslate.
2. **Target Language**: Choose your destination language (can be different from NVDA's active language!).
